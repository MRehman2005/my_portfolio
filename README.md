# Muhammad Rehman — AI Engineer Portfolio

A responsive, modern portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive styling and animations
- `script.js` — navigation, scroll reveal, progress bar and theme toggle

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize before publishing
1. Replace `your.email@example.com` in `index.html` with your real email.
2. Replace the LinkedIn placeholder with your actual LinkedIn URL.
3. Add your resume PDF and change the hero/contact buttons if desired.
4. Update project links for projects that have public repositories.

## Deploy
This static site can be deployed on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
